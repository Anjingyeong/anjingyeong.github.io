# 포트폴리오 수정 작업 순서

이 폴더의 문서는 Codex가 한 번에 하나씩 읽고 작업하도록 만든 단계별 지시서다.

## 작업 순서

1. `01-hero-about.md`
2. `02-smart-safety-ai.md`
3. `03-smart-safety-fullstack.md`
4. `04-skills-experience.md`
5. `05-print-readme-sync.md`

한 문서의 수정·테스트·빌드·화면 검수가 끝난 뒤 다음 문서로 넘어간다.

## 공통 실행 프롬프트

```text
docs/portfolio-tasks/<파일명>.md를 처음부터 끝까지 읽어라.

이번 작업에서는 해당 문서에 지정된 범위만 수정한다.

규칙:
1. 현재 main의 관련 파일과 테스트를 먼저 읽는다.
2. 문서의 최종 문구는 임의로 다시 작성하지 않는다.
3. 확인되지 않은 숫자·역할·팀 규모를 만들지 않는다.
4. 다른 프로젝트와 관련 없는 파일은 수정하지 않는다.
5. 관련 테스트를 통과시킨 뒤 npm run build를 실행한다.
6. 실패하면 다음 단계로 넘어가지 말고 현재 단계만 수정한다.
7. 완료 후 변경 파일, 적용 문구, 테스트 결과, 빌드 결과와 남은 위험을 보고한다.
8. 작업 중 요구사항이 기억나지 않으면 추측하지 말고 이 문서를 다시 읽는다.
```

## 작업 전 확인할 값

- 스마트 안전 관제 실제 팀 인원
- 팀장 여부
- ID Switch `8건 → 1건`
- Mean Track Coverage `35.76% → 49.70%`
- 51D·54D 성능 수치
- TensorRT 비교 수치
- End-to-End 이벤트 수 `29건`
- 평균 지연 `20.931ms`, p95 `26ms`
- SK쉴더스 과정의 정확한 시작·종료일

확인되지 않은 내용은 임의로 공개 문구에 넣지 않는다.
